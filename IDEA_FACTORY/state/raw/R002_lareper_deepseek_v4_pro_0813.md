IDEA: Проверка первого экрана через «мгновенный скриншот-тест» на 3 устройствах
KNOB: METHOD: Сделайте 3 скриншота index.html (desktop 1440px, mobile 375px, tablet 768px) через headless-браузер (Chrome DevTools → Device Toolbar или Playwright). Сравните: виден ли h1 полностью без прокрутки, виден ли CTA-элемент, нет ли перекрытий текста. Замерьте время до первой отрисовки через Performance panel.
EFFECT: За 5 минут выявляете проблемы первого экрана (обрезка заголовка, невидимый CTA на мобильных), которые напрямую убивают конверсию.
RISK: Скриншоты не показывают динамику скролла и hover-состояний, но для статичной проверки достаточно.
ROLLBACK: Не требуется — это метод измерения, файлы не меняются.
VERIFY: Откройте DevTools → Device Toolbar → выберите 3 разрешения → скриншот → визуально проверьте за 2 минуты.
PRIORITY: 1 — первый экран решает 80% конверсии, а проверка занимает минуты.

IDEA: A/B-тест заголовка через локальную копию с заменой h1
KNOB: METHOD: Создайте копию index.html (например, index-ab.html). Замените h1 на вариант: «Клиенты из Яндекса за 2 дня — без переделки сайта». Откройте обе версии в двух вкладках, попросите 3 человек (или сами) за 10 секунд ответить: «Что предлагают?» и «Что делать?». Сравните формулировки ответов.
EFFECT: Быстро проверяете, какая формулировка h1 понятнее и конкретнее, без деплоя и трафика.
RISK: Малый размер выборки не даёт статистической значимости, но выявляет явные проблемы понимания.
ROLLBACK: Удалите index-ab.html — оригинал не тронут.
VERIFY: За 10 минут: сделайте копию, замените текст, проведите опрос 3 человек.
PRIORITY: 2 — ясность оффера критична, но требует ручного опроса.

IDEA: Проверка скорости через Lighthouse с эмуляцией Slow 4G
KNOB: METHOD: Откройте DevTools → Lighthouse → выберите Mobile, эмуляция Slow 4G, throttling CPU 4x. Прогоните аудит. Запишите: Performance score, Largest Contentful Paint (LCP), Total Blocking Time (TBT). Если LCP > 2.5s — найдите render-blocking ресурсы (шрифты Google, CSS) во вкладке Opportunities.
EFFECT: За 3 минуты получаете объективные метрики скорости и список конкретных исправлений (preload, critical CSS), которые можно применить в следующих итерациях.
RISK: Локальный Lighthouse не учитывает реальный хостинг и сеть, но для относительной оценки годится.
ROLLBACK: Не требуется — аудит не меняет файлы.
VERIFY: DevTools → Lighthouse → Generate report → смотрите LCP и TBT.
PRIORITY: 1 — скорость напрямую влияет на SEO и конверсию, а проверка бесплатна и быстра.

KNOB: для всех `<a>` с `target="_blank"` (например, ссылки на VK и Telegram) добавить `rel="noopener noreferrer"`

PRIORITY: 2 – важный security‑апдейт, быстрый в реализации.

EFFECT: Сокращает время DNS‑lookup при переходе по внешним ссылкам, ускоряя восприятие скорости сайта.  
RISK: Практически нулевой; браузеры могут игнорировать, но это безопасно.  
ROLLBACK: Удалить две строки из `<head>`.  
VERIFY: В Chrome DevTools → Network → DNS, перезагрузить страницу и убедиться, что запросы DNS к указанным доменам выполнены заранее (отмечены как “prefetched”).

IDEA: Инлайн‑критический CSS + preload основного стиля  
KNOB: 1) Выделить CSS, необходимый для первого экрана (hero, навигация, типографика) и вставить его в `<style>` внутри `<head>`.  
2) Заменить текущий `<link rel="stylesheet" href="style.css">` на  
```html
<link rel="preload" as="style" href="style.css" onload="this.rel='stylesheet'">
<noscript><link rel="stylesheet" href="style.css"></noscript>
```  
EFFECT: Убирает блокирующий рендер ресурс, ускоряя First Contentful Paint и Time‑to‑Interactive, особенно на медленных соединениях.  
RISK: Неправильно выделенный критический CSS может привести к FOUC (миганию без стилей) или к отсутствию стилей выше «складки». Требует тестирования.  
ROLLBACK: Восстановить оригинальный `<link rel="stylesheet" href="style.css">` и удалить инлайн‑блок.  
VERIFY: Запустить Lighthouse → Performance, сравнить FCP/TTI до и после; визуально убедиться, что макет не «дёргается» при загрузке.  
PRIORITY: 1 – значительный выигрыш в скорости при умеренной работе.  

IDEA: Явный meta‑тег robots для индексации  
KNOB: добавить в `<head>` строку  
```html

```  
EFFECT: Ясно указывает поисковым системам индексировать страницу и следовать по ссылкам, устраняя любые неопределённости в поведении роботов.  
RISK: Отсутствие – нулевой; добавление не конфликтует с другими директивами, но может быть переопределено robots.txt.  
ROLLBACK: Удалить добавленный meta‑тег.  
VERIFY: Открыть исходный код, убедиться в наличии тега; в Google Search Console выполнить проверку URL → убедиться, что статус «Indexed».  
PRIORITY: 3 – небольшое улучшение SEO, легко реализуемо.

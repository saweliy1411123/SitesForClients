IDEA: Hash‑Based CTA Variant Switch (A/B‑тест без деплоя)  
KNOB: METHOD: добавить в конец `<body>` небольшую «скриптовую» строку (можно выполнить в консоли) — `if(location.hash==='#cta2'){document.querySelectorAll('.btn-primary').forEach(b=>b.textContent='Получить демо бесплатно');}`; затем менять хеш в адресной строке (`#cta1` — оригинал, `#cta2` — вариант) и наблюдать изменение текста/стиля CTA в реальном времени.  
EFFECT: позволяет сравнить два варианта CTA (текст, цвет, размер) без изменения кода, измеряя клики или время до клика через консольный `click`‑логгер.  
RISK: требует согласования с владельцем, если изменение текста может вводить в заблуждение — но изменения только в браузере текущего пользователя.  
ROLLBACK: удалить/закомментировать строку скрипта или просто убрать хеш из URL и перезагрузить страницу.  
VERIFY: открыть страницу, добавить `#cta2` к URL, убедиться, что все кнопки `.btn-primary` изменили текст/стиль; вернуть `#cta1` — вернётся исходный вариант.  
PRIORITY: 1 — быстрый способ проверить влияние CTA‑текста на конверсию без кода, занимает ≤ 3 минуты.  

IDEA: Performance‑Timing Snapshot (TTFB / DOMContentLoaded / Load)  
KNOB: METHOD: в консоли выполнить скрипт, который читает `performance.timing` и выводит ключевые метрики: `const t = performance.timing; console.table({TTFB: t.responseStart‑t.requestStart, DOMContentLoaded: t.domContentLoadedEventEnd‑t.navigationStart, Load: t.loadEventEnd‑t.navigationStart});`  
EFFECT: даёт мгновенный базовый профиль скорости загрузки (время до первого байта, готовность DOM, полная загрузка), позволяя сравнить влияние изменений (например, предзагрузка шрифтов) без повторных билдов.  
RISK: нет (только чтение API).  
ROLLBACK: не требуется — скрипт не меняет страницу.  
VERIFY: после выполнения скрипта увидеть таблицу с цифрами; повторить после внесения гипотетических изменений (например, добавить `<link rel="preload">` в DevTools → Sources) и сравнить значения.  
PRIORITY: 3 — полезно для оценки скорости, но менее критично, чем SEO и CTA‑тест; проверка занимает ≤ 2 минуты.

IDEA: robots.txt + sitemap.xml для индексации при деплое
KNOB: METHOD: создать рядом с index.html два файла: `robots.txt` (`User-agent: *\nAllow: /\nSitemap: https://<домен>/sitemap.xml`) и `sitemap.xml` с одним URL `<loc>https://<домен>/</loc>`. Домен подставить после размещения — требует решения владельца (хостинг).
EFFECT: Яндекс/Google корректно индексируют лендинг с первого захода, не теряют его и быстрее показывают по запросам «лендинг Пермь / сайт за 2 дня».
RISK: без реального домена файлы бесполезны — заглушки нельзя публиковать.
ROLLBACK: удалить два файла (`del robots.txt sitemap.xml`) — index.html не затрагивается.
VERIFY: 2 мин — после деплоя открыть `https://<домен>/robots.txt` в браузере и в Яндекс.Вебмастере нажать «Проверить robots.txt».
PRIORITY: 2 — важно, но заблокировано наличием домена.

IDEA: Контраст muted-текста — точечный аудит конкретных значений
KNOB: METHOD: в DevTools → Elements выделить элементы с `color:var(--muted)` (подписи, `.per`, `.hero-note`, футер), в панели Computed кликнуть по свотчу цвета → посмотреть ratio. Порог: 4.5:1 для обычного текста. Если меньше — не менять тему, а поднять только значение `--muted` на 1–2 ступени светлее (например, с `#8a8a94` до `#9a9aa4`) в `:root`.
EFFECT: прохождение WCAG AA, читаемость мелких подписей на мобильных при ярком свете — меньше потерянных посетителей на этапе цены.
RISK: осветление muted снижает визуальную иерархию «приглушённости» — менять минимально.
ROLLBACK: `git checkout -- index.html` (правка одной строки в `:root`).
VERIFY: 3 мин — DevTools → Computed → контраст-индикатор на 5–6 элементах с var(--muted); записать ratio до/после.
PRIORITY: 1 — дешёвая правка одной переменной, прямой эффект на читаемость и a11y.

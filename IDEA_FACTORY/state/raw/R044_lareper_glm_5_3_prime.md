RISK: Конкуренты могут быть в другой нише/ценовом сегменте — сравнение смещённое.
ROLLBACK: Файл не изменяется; скриншоты удалить из IDEA_FACTORY/shots/.
VERIFY: 10 минут на всё (скриншоты + 3 показа).

EFFECT: Выявляет слабую визуальную иерархию длинной страницы; пользователь скроллит быстро — блоки должны считываться «пятнами».

ROLLBACK: Метод только диагностирует; любые CSS-правки после — через git checkout index.html.

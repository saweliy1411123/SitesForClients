IDEA: Метод «глухой скриншот-тест» — оценка первого экрана по статичному кадру без скролла
KNOB: METHOD: (1) Открыть index.html в Chrome, DevTools → Toggle device toolbar → iPhone SE (375px). (2) Нажать Ctrl+Shift+P → «Capture screenshot» (только viewport). (3) Отправить скриншот 3 людям в мессенджер с вопросом: «Что продают? Сколько стоит? Что сделать дальше?» — без возможности скроллить. (4) Если ≥2 из 3 не ответили на все три вопроса за 10 секунд просмотра — hero требует правки (подзаголовок/CTA/доказательства). Повторить тот же кадр после правок для сравнения.
EFFECT: Объективная проверка читаемости hero на мобильном за 5 минут без деплоя и аналитики; фиксирует именно «первый кадр», который видит 100% посетителей.
RISK: Малая выборка (3 человека) даёт шумный сигнал — выводы использовать как направление, а не как статистику.
ROLLBACK: Метод ничего не меняет в файлах; скриншоты хранить в IDEA_FACTORY/, удалить при ненадобности.
VERIFY: Сам прогон занимает 5–7 минут; критерий — 2 из 3 респондентов верно назвали оффер, цену-модель (бесплатное демо) и следующее действие.
PRIORITY: 1 — hero определяет всю конверсию, а текущий метод проверки (5-секундный, I-00062) не проверяет мобильный кадр изолированно.

IDEA: Метод «контрастный силуэт» — проверка иерархии страницы в режиме Grayscale + Blur
KNOB: METHOD: (1) Открыть index.html, DevTools → Rendering → Emulate vision deficiencies → «Blurred vision» (или установить CSS-фильтр `html{filter:grayscale(1) blur(1.5px)}` через DevTools → Elements → documentElement → element.style). (2) Пролистать страницу за 30 секунд и отметить: видно ли, где цена, где CTA, где демо-концепты. (3) Если CTA-кнопка и цена не «выстреливают» из силуэта страницы — усилить контраст/размер этих элементов. (4) Убрать фильтр, сравнить до/после на копии index.improved.html.
EFFECT: Выявляет слабую визуальную иерархию, которую не видно при нормальном зрении; имитирует беглое сканирование реального посетителя и проверяет WCAG-контраст без инструментов.
RISK: Размытие — лишь приближение к реальному «сканирующему» просмотру, не заменяет eye-tracking.
ROLLBACK: Фильтр применяется только в DevTools на живой странице, файл не меняется — откат не нужен.
VERIFY: Весь тест 2–3 минуты; критерий — CTA и цена различимы в размытом силуэте с расстояния «прищура».
PRIORITY: 2 — дополняет контраст-аудит I-00086 (тот проверяет цифры WCAG, этот — визуальную иерархию целиком).

IDEA: I‑00064 — «Тёмный режим с переключателем и авто‑детекцией»

KNOB: Добавить в `<head>` CSS‑переменные для цветовой схемы (‑‑bg, ‑‑text, ‑‑accent) и медиазапрос `@media (prefers-color-scheme: dark)`. Вставить в `<body>` небольшую кнопку‑переключатель `<button id="theme-toggle" aria-label="Переключить тему">🌙</button>` с JS‑логикой, сохраняющей выбор в `localStorage` и переключающей класс `dark` у `<html>`.

EFFECT: Улучшит восприятие сайта у пользователей, предпочитающих тёмный интерфейс, повысит показатель Core Web Vitals за счёт уменьшения яркости и потенциально увеличит конверсию на мобильных устройствах (30 % трафика в России используют тёмный режим).

RISK: Требует небольшого JS‑кода (≈30 строк) – потенциальный конфликт с существующим скриптом, но риск минимален при изоляции в IIFE.

ROLLBACK: `git checkout -- index.html` (или удалить добавленные строки и скрипт).

VERIFY: Открыть страницу в Chrome, включить DevTools → Application → Local Storage, убедиться, что `theme` сохраняется; переключить режим вручную и проверить, что цвета меняются без перезагрузки, а также что `prefers-color-scheme` автоматически задаёт тёмный вид при первом открытии.

PRIORITY: **1** – быстрый (≈10 мин) апдейт, высокий пользовательский эффект и положительное SEO‑сообщение о доступности.

IDEA: I‑00066 — «Хлебные крошки + schema.org BreadcrumbList»

KNOB: Вставить перед основным контентом `<nav aria-label="Навигация по сайту" class="breadcrumbs"><ul itemscope itemtype="https://schema.org/BreadcrumbList">…</ul></nav>` с элементами:
```html
<li itemprop="itemListElement" itemscope
    itemtype="https://schema.org/ListItem">
  <a itemprop="item" href="/"><span itemprop="name">Главная</span></a>
  <meta itemprop="position" content="1"/>
</li>
```
(и аналогично для текущей секции «Лендинг за 2 дня»). Добавить базовый CSS для компактного отображения.

EFFECT: Улучшит навигацию для пользователей и поисковых систем, повысит шанс появления в поисковой выдаче с «хлебными крошками», улучшит показатель SEO‑структуры без изменения контента.

RISK: Требует небольших правок HTML; если разместить внутри уже существующего `<section>`, может нарушить вёрстку, но проверка в локальном билде устраняет риск.

ROLLBACK: `git checkout -- index.html` (удалить вставленный `<nav>` и связанные стили).

VERIFY: Включить в Chrome DevTools → Rich Results Test URL `file://…/index.html`; убедиться, что BreadcrumbList распознан без ошибок. Проверить визуально, что крошки не «вываливаются» за пределы контейнера.

PRIORITY: **2** – умеренный эффект (SEO + UX), простая реализация, но менее критична, чем тёмный режим, поэтому ставим второй приоритет.

EFFECT: Позволит мгновенно оценить, как изменение формулировки влияет на количество кликов без изменения кода сайта.

PRIORITY: 1 – быстрый способ проверить гипотезу о формулировке CTA, требует минимум времени и не меняет код.

IDEA: URL‑parameter variant selector (A/B)  
KNOB: METHOD: В консоли выполнить `const v = new URLSearchParams(location.search).get('hero'); if(v==='alt'){document.querySelector('h1').textContent='Альтернативный заголовок';}`; затем добавить к ссылке тестовый параметр `?hero=alt`.  
EFFECT: Позволит сравнить два варианта заголовка без правки файлов, используя простую URL‑настройку; удобно для быстрой проверки конверсии (клики по CTA) через встроенный счётчик.  
RISK: Не сохраняет выбранный вариант между сеансами, поэтому результаты ограничены текущей сессией; может конфликтовать с другими параметрами URL.  
ROLLBACK: Убрать параметр из URL — скрипт не будет менять заголовок, страница вернётся к оригиналу.  
VERIFY: Открыть страницу с `?hero=alt`, проверить визуально изменение заголовка, кликнуть по CTA и посмотреть счётчик в `sessionStorage` (как в предыдущем методе) или в аналитике.  
PRIORITY: 2 – обеспечивает более «чистый» способ переключения контента, пригоден для демонстраций клиенту, но требует небольшого скрипта.

IDEA: Persistent variant A/B via localStorage  
KNOB: METHOD: В консоли выполнить скрипт, который при первой загрузке генерирует случайное значение `0` или `1`, сохраняет его в `localStorage.setItem('heroVariant', v)`, а затем в зависимости от `v` меняет текст CTA (или заголовок) через `document.querySelector`.  
EFFECT: Позволит собрать статистику по двум вариантам в течение нескольких сеансов без изменения кода сайта; удобно для быстрого «мультисессийного» A/B‑теста.  
RISK: Требует, чтобы пользователь согласился с локальным хранилищем; результаты могут быть смещены, если тестировать только на одном устройстве.  
ROLLBACK: Очистить `localStorage.removeItem('heroVariant')` и перезагрузить страницу — вариант будет выбран заново.  
VERIFY: После выполнения скрипта открыть несколько раз страницу (или открыть в новых вкладках), убедиться, что вариант сохраняется, собрать количество кликов по CTA через `sessionStorage`‑счётчик и сравнить между вариантами.  
PRIORITY: 3 – даёт более длительный сбор данных, но требует больше времени для накопления кликов; полезен, если первый и второй методы показывают интересные различия.

IDEA: I-00061 — «Мгновенный аудит доступности через axe‑core bookmarklet»  
KNOB: Сохранить в закладки следующий JavaScript‑bookmarklet:  

```javascript
javascript:(function(){var s=document.createElement('script');s.src='https://cdnjs.cloudflare.com/ajax/libs/axe-core/4.9.1/axe.min.js';s.onload=function(){axe.run(function(err,result){if(err){console.error(err)}else{console.table(result.violations)}})};document.head.appendChild(s);})();
```  

Запустить его на открытой локальной копии `index.html`. axe‑core выполнит проверку и выведет в консоль список нарушений (цветовой контраст, отсутствие ARIA‑меток, недоступные ссылки и т.д.).  
EFFECT: За ≈ 5 секунд получает полный список проблем доступности без установки дополнительных инструментов, позволяя быстро решить мелкие баги, которые могут снижать конверсию и SEO.  
RISK: Требует доступа к интернету для загрузки библиотеки; в корпоративных сетях может быть блокировка CDN.  
ROLLBACK: Нет изменений в файлах — только одноразовый скрипт в консоли.  
VERIFY: После запуска bookmarklet увидеть в консоли массив `violations`; убедиться, что количество найденных проблем соответствует ожиданиям (например, 0 для «aria‑label» у всех ссылок).  
PRIORITY: 3 — полезно для обеспечения базовой доступности, но менее срочно, чем проверка копии или CLS.

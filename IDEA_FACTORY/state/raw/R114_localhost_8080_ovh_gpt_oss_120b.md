```js

  const theme = params.get('theme');
  if (theme) document.documentElement.dataset.theme = theme;
})();
```

```css
:root[data-theme="dark"] { --bg:#111; --text:#eee; --grad:#ff00ff; }
```  

RISK: Требует согласования с владельцем, если тема меняет бренд‑цвета; может вводить конфликт с уже существующими переменными.

IDEA: CTA‑Visibility Timing (время до первой видимости CTA)  
KNOB: METHOD: В консоли выполнить скрипт, который использует `IntersectionObserver` для элемента `.btn-primary` (первый CTA) и выводит в консоль `performance.now()`‑метку, когда CTA впервые попадает в область видимости.  

```js
(() => {
  const cta = document.querySelector('.btn-primary');
  if (!cta) return console.warn('CTA not found');
  const observer = new IntersectionObserver(entries => {
    entries.forEach(e => {
      if (e.isIntersecting) {
        console.log('CTA first visible at', Math.round(performance.now()), 'ms');
        observer.disconnect();
      }
    });
  });
  observer.observe(cta);
})();
```  

EFFECT: Даёт количественную метрику «время до первой возможности конверсии», позволяя оценить, насколько быстро пользователь может кликнуть CTA после загрузки (важно для мобильных устройств и длинных hero‑секций).  
RISK: Не влияет на реальных пользователей; измерение только в текущей сессии.  
ROLLBACK: Перезагрузить страницу — наблюдатель исчезнет.  
VERIFY: Открыть страницу в обычном режиме, открыть консоль, вставить скрипт, наблюдать вывод (например, `CTA first visible at 1243 ms`). Сравнить с изменённым вариантом (например, уменьшив высоту hero).  
PRIORITY: 2 – помогает быстро понять, нужна ли оптимизация первого экрана или перемещение CTA выше, что критично для конверсии.

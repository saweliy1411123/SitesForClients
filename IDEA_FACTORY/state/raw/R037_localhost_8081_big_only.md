KNOB: METHOD: В конец `<body>` вставить скрипт‑однострочник:  
```js
new PerformanceObserver(l=>{let cls=0;l.getEntries().forEach(e=>cls+=e.value);console.log('CLS:',cls);})
.observe({type:'layout-shift',buffered:true});
```  
EFFECT: При загрузке страницы в консоль будет выведено суммарное значение CLS, позволяя оценить, влияют ли новые элементы (анимации, динамический контент) на визуальную стабильность.  
RISK: Скрипт лишь выводит данные, не меняет страницу; небольшое влияние на производительность (меньше 1 мс).  
ROLLBACK: Удалить вставленный `<script>`; `git checkout index.html` откатит изменения.  
VERIFY: Открыть страницу в Chrome, открыть DevTools → Console, перезагрузить → увидеть значение CLS (должно быть < 0.1). Сравнить до/после изменения в 2‑5 минут.  
PRIORITY: 2 – важный SEO‑показатель, проверка занимает секунды, помогает избежать ухудшения ранжирования.

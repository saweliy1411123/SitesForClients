# premium-glassmorphism-button


**Name:** `premium-glassmorphism-button`
**When to apply:** На любом статическом лендинге, где требуется премиальный вид кнопок.
**SAFE CSS:**
```css
.premium-glassmorphism-button {
background: rgba(255, 255, 255, 0.07);
backdrop-filter: blur(12px);
border: 1px solid rgba(255, 255, 255, 0.1);
border-radius: 12px;
padding: 15px 30px;
font-size: 16px;
cursor: pointer;
transition: background-color 0.2s ease;
}
.premium-glassmorphism-button:hover {
background: rgba(255, 255, 255, 0.1);
backdrop-filter: blur(15px);
}
.premium-glassmorphism-button:focus {
outline: none;
box-shadow: 0px 0px 0px 2px rgba(255, 255, 255, 0.1);
}
```
**SAFE JS:**
```javascript
// нет
```

## Когда применять
Добавление премиального эффекта стекла и блура к кнопкам призыва к действию, что делает их более привлекательными и заметными для пользователя.

## Проверка
Проверить, что изменения не нарушают функциональность кнопок и не ухудшают их читаемость.

# SKILL — «Читаемый оффер за 5 секунд» (hero-clarity-fix, переносимый паттерн первого экрана)

Название: **hero-clarity-fix**. Когда применять: любой статический лендинг услуг, где первый экран должен за 5 секунд ответить «что, кому, за сколько, что делать».
Шаги:
1. Аудит hero по чек-листу: h1 содержит выгоду+срок (есть: «за 2 дня», «клиенты находят в Яндексе»), подзаголовок `.sub` (L460) отвечает «как именно», CTA-ссылка (L462) содержит глагол+результат, рядом с CTA есть одно доказательство (цифра/факт) и одно снятие риска (бесплатно/без обязательств).
2. Проверить, что между h1 и CTA не больше 2 смысловых блоков; лишнее перенести ниже.
3. Добавить под CTA строку-снятие риска (если её нет): `<p class="cta-note">Демо бесплатно — платите только если понравится</p>` (формулировку сверить с реальным оффером на сайте).
4. Проверить контраст `.sub` (#c3cad9 на тёмном фоне) ≥ 4.5:1.
5. Проверка: «глухой скриншот-тест» — скриншот первого экрана на 375px, показать 5 секунд, спросить: что предлагается, сколько стоит, что нажать.
SAFE CSS:
```css
.cta-note{color:#8b93a7;font-size:14px;margin-top:12px;text-align:center}
@media (max-width:600px){.cta-note{font-size:13px}}
```

## Когда применять
рост конверсии hero в клик по CTA за счёт явного снятия риска и сокращения пути «понял → нажал».

## Проверка
5-секундный скриншот-тест на 375px + контраст-проверка `.sub` в DevTools (2–4 мин).
